# admin-web — 운영자 모니터링 화면

`scheduling` 백엔드의 5개 운영자 엔드포인트(`GET /operator/live`, `/operator/today`,
`/operator/not-ready`, `/operator/credit-warnings`, `/operator/sessions`)를 한 페이지에 세로로
쌓아 보여준다. 라우터 없음. 등록·배정·시간표 편집·크레딧 수동 조정은 범위 밖이다
(`docs/superpowers/specs/2026-08-08-operator-monitoring-design.md` §1).

## 시크릿은 인증이 아니다 — 반드시 읽는다

**`VITE_OPERATOR_SECRET` 은 브라우저 번들에 평문으로 박힌다.** Vite 는 `VITE_` 접두사가 붙은
환경변수를 빌드 시점에 그대로 클라이언트 JS 에 인라인한다. `npm run build` 로 만든
`dist/assets/*.js` 를 열어 보면 이 값이 문자열 그대로 들어 있다 — 난독화도, 서버 사이드
보관도 없다.

즉 이 화면에 접속할 수 있는 사람은 누구든 개발자 도구로 시크릿을 읽어낼 수 있고, 그 값으로
`scheduling` 의 운영자 API 를 직접 호출해 **전체 아동의 보호자 연락처를 포함한 모든 데이터에
닿을 수 있다.** 시크릿 헤더(`X-Operator-Secret`)는 "실수로 열린 엔드포인트를 우연히 두드리는
것"만 막는 장치이지, 누가 봐도 되는지를 가리는 인증이 아니다 — 시크릿을 아는 사람은 전부
동일한 권한을 갖고, 누가 무엇을 봤는지 감사 기록도 전혀 남지 않는다
(`scheduling/src/middleware/operatorOnly.ts` 상단 주석, 설계 §2.1).

**그래서 `scheduling` 서버는 `127.0.0.1`(loopback)에만 바인딩한다.** 시크릿 하나가 전체 아동
개인정보의 마지막 방어선이 되는 상황을 만들지 않기 위한 짝이다. 이 화면과 백엔드를
localhost 밖(사내망, 클라우드, 무엇이든)에 그대로 올리면 이 장치는 아무것도 막지 못한다.

**운영 환경 배포는 설계 §5의 진짜 인증(자체 로그인, 역할, 감사 로그)이 끝난 뒤에만 한다.**
이 문장이 이 문서에서 가장 중요하다.

## 설정

```bash
cp .env.example .env.local
# .env.local 을 열어 VITE_API_BASE, VITE_OPERATOR_SECRET 을 채운다.
# VITE_OPERATOR_SECRET 은 scheduling/.env 의 OPERATOR_SECRET 과 같은 값이어야 한다.
npm install
npm run dev
```

`.env.local` 은 커밋하지 않는다(gitignore 됨).

## 화면 구성 (설계 §4)

1. **실시간 요약** — 10초 폴링. 탭이 백그라운드면(`document.visibilityState !== 'visible'`)
   폴링을 건너뛴다. 네 칸은 이름이 실제로 세는 것만 말한다: `heartbeatLate` 는 선생님
   브라우저의 생존신호 지연이지 아이의 연결이 아니고, `readinessUnknown` 은 확인이 실패한
   게 아니라 아무 확인도 돌지 않았다는 뜻이다. 서버는 학생-선생님 연결이 P2P 라 아이 쪽
   상태를 관측할 수단이 없다 — 그래서 이 화면도 그것을 아는 척하지 않는다.
2. **오늘 집계** — 날짜별 상태 건수. 사후 확인용이라 폴링하지 않는다.
3. **준비 실패 목록** — 프리체크 파이프라인이 아직 없어(§9 오픈이슈) 모든 항목이 정직하게
   "확인 안 됨"으로 나온다.
4. **크레딧 경고 목록** — 크레딧이 쌓이기만 하고 소진할 슬롯이 없어지는 등록을 보여준다.
5. **세션 검색** — 학생명·선생님명(부분 일치)과 날짜로 조회. 문의 대응용.

## 오류 표시 (결정 #3)

각 섹션은 로딩/오류/완료 상태를 독립적으로 관리한다. 요청이 실패하면(시크릿이 틀려 404가
오는 경우 포함) 빈 표가 아니라 눈에 띄는 빨간 오류 문구를 보여준다 — "데이터 없음"과
"불러오지 못함"을 같은 화면으로 만들지 않기 위해서다.
